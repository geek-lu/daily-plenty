# src/features/common/ui/

> L2 | 父级: ../CLAUDE.md

两端共用的业务 UI 原子；不含页面版式与导航。

- EntryDrawer.tsx：录入/编辑表单，组合分类、个人模板和删除原因确认；编辑时只显示保存修改，保留已退出付款人。
- BottomDrawer.tsx：React Portal 抽屉容器；手机底部上滑，PC（≥1024px）由 globals.css 改为右侧滑出面板。消费 Presence 退出状态，ref 仅用于焦点和表单滚动。
- DeleteEntryDialog.tsx：原因必选的删除确认，其他原因必填说明；取消不发请求，失败保留输入。
- EntryRow.tsx：两端共用账单列表项，账单主体分分类、日期与付款人/收款人、备注（空时暂无备注）三行，字号分别为 15/12/11px（日期付款人墨色、备注灰色）、行间距 3px、主行上下留白 14px，点击仅查看详情；底部独立折叠看板左侧展开/收起、右侧写评论按需打开输入；首页已有评论默认展示，明细通过 defaultCommentsExpanded=false 默认收起、收起时也查询评论以外显总数，无评论不占位，收起输入保留草稿；折叠复用 ui/Collapse 的高度/透明度过渡，关闭时 inert，箭头平滑旋转。
- entry-item.css：列表项主体、同一行右侧居中的 18px/500 主题红金额（手机为图标/信息/金额三列，正负号区分收支）、底部折叠看板与移动端排版（看板下距 8px、水平内边距 10px，评论上下留白 6px，两端折叠栏高 34px、按钮上下内边距 4px；PC 主行内边距 16px、评论上距 10px、每项上下留白 12px）；评论采用同字体的小字附注风格：暖纸底、3px 微圆角、无头像/徽标；12px 姓名与正文、11px 时间与栏标题，回复细线缩进；40px 输入与浅底描边发送按钮并排，触屏输入保留 16px 避免聚焦缩放。
- CategoryIcon.tsx / InterfaceIcon.tsx：分类与界面 SVG 图标，统一 1.75px 笔画。
- preferences/：分类创建、模板保存、模板列表。

BottomDrawer 的 side 属性允许手机筛选从右侧滑出；复用焦点约束、背景滚动锁、关闭恢复及键盘视口适配。

折叠栏使用纸色底、暖灰操作文字，仅评论总条数（含回复）使用朱红，发布成功后同步数量，内部不重复数量。
