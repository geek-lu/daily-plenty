# 日日有余 · 视觉规范

## 1. Visual Theme & Atmosphere

MUJI 灵感：纸感米白、墨灰文字、暗红印章、小面积橄榄绿。重视秩序、留白和日常生活的温度。
这是为本产品独立设计的规范，不是 MUJI 官方设计规范，也未使用其品牌资产。

## 2. Color Palette & Roles

背景 paper #f6f5f0；表面 surface #fffefa；文字 ink #30332e；次要 muted #72766a；边框 line #e3e3d9。
品牌 accent #7f0019；品牌浅底 accent-soft #f7eff1；收入 positive #52654b；绿色浅底 sage #edf0e7。
界面收敛为米白、墨灰和少量暗红；导航与卡片使用 surface，页面及评论用 paper。绿色仅用于收入/结余等语义，不用于导航装饰。以留白、细线和低色差传达自然材质的安静感，不铺木色大块或仿木纹。
颜色辅助状态，收入/支出始终有文字和正负号，错误同时提供文字解释。

## 3. Typography Rules

系统无衬线字体用于操作，中文系统宋体用于品牌及展示标题，避免远程字体。
正文 14–16px / 1.65；辅助 12px；标题 28–40px；总金额 36–48px。
金额使用 tabular-nums，避免数字变化造成布局抖动。

## 4. Component Stylings

按钮最小高度 44px；控件清晰 focus-visible；圆角 4/8/12px，避免大面积胶囊和重阴影。
账单按日期分组，行可点开编辑；记账使用有标签的表单，手机呈底部弹层。
主要 CTA 使用暗红；删除必须二次确认且演示允许撤销。

图标尺寸：底部导航与分类选择 24px、桌面导航与常规操作 20px、账单分类 22px、模板 20px、统计辅助图标 16px，主记账加号 24px。导航语义固定为账簿/柱状图/明细清单/双人，月份使用日历；全部使用 SVG，不使用字符替代图标。
分类图标采用 24×24 viewBox、1.75px 线宽、currentColor 的本地 SVG；选择器为移动端 4/5 列网格，按钮至少 44px，中文标签与 aria-pressed 同时标识选中状态。

## 5. Layout Principles

间距采用 4/8/12/16/24/32/48/64px；大屏使用居中内容区和底部导航，不再使用侧栏。
四个页面共用固定底部四栏导航（账本/统计/明细/我们），内容底部为导航和手势区留白；各页最大宽度和功能布局独立。底栏中央为独立「＋ 记一笔」动作，原地打开共用底部抽屉；首页主区也进入同一抽屉。

登录、初始化、认证加载与认证错误页面不显示业务底栏，也不预留导航高度；只有认证就绪后四个业务页面显示底栏，退出后同步移除。

## 6. Depth & Elevation

表面通过细边框区分，弹层及左滑展开的账单前景使用轻阴影。无玻璃态、霓虹色；渐变仅用于用户指定的紧凑 AI 来源标签。
四页切换：内容以 180ms、cubic-bezier(.22,.61,.36,1) 从 0.92 透明度轻微淡入至 1，不位移、不从全透明闪入；底栏保持固定，选中颜色和浅底以 200ms ease-out 过渡。底栏禁用 iOS 原生触摸高亮，记账按压颜色平滑过渡，保留键盘焦点环。页面加载边界只包裹业务内容。数据刷新不重播整页动画，减少动态效果设置下禁用动效。

## 7. Do's and Don'ts

让金额先于图表，录入先于配置；默认今天、当前成员、支出。
不要用付款人推断创建人；不要把示例数据说成真实同步；不要只靠颜色传达状态。

## 8. Responsive Behavior

各宽度均显示固定底部四栏导航；手机竖屏以单列主区为主，阔屏增加控件列数。
650px 下快捷模板优先于最近账单；不挤压页标题，记账入口在底栏中央常驻，并在账本主区提供快捷入口。
评审表格转为带字段名称的纵向卡片，保留表头与表格角色；架构节点纵向排列，流程切换为两列按钮。
手机输入框和下拉框至少 16px，操作点击区至少 44px；380px 下日期与付款人分行，防止原生日期控件挤出屏幕。
弹层尊重 safe-area；VisualViewport 跟随键盘更新可视高度和底边，底部保存按钮吸附，打开时锁住页面滚动。
金额 input 使用 inputmode=decimal；按用户要求禁用页面双指缩放，viewport、touch-action 与 Safari 手势适配配合，单指滚动与点击保留；遵循 reduced-motion。总金额允许换行，避免大数溢出。
目标宽度 320px、375px、390px、430px、768px、1440px；当前已检查结构与样式语法，真实渲染、键盘行为和鸿蒙实机兼容性仍待验证。

## 9. Agent Prompt Guide / Tailwind 映射

正式工程采用 Tailwind CSS v4 的 @theme：

```css
@import 'tailwindcss';
@theme {
  --color-paper: #f6f5f0;
  --color-surface: #fffefa;
  --color-ink: #30332e;
  --color-muted: #72766a;
  --color-line: #e3e3d9;
  --color-accent: #7f0019;
  --color-accent-soft: #f7eff1;
  --color-positive: #52654b;
  --color-sage: #edf0e7;
}
```

本轮 HTML 使用独立 CSS 落实相同令牌，确保双击即可离线评审；未安装 Next.js 或 Tailwind 构建工具。

独立全部账单 /records：页面宽度 max-w-6xl，底部四栏切页；默认紧凑搜索与筛选入口，完整筛选按需展开、应用后收起；条件摘要 → 全量汇总 → 分页列表。
目标：iPhone 13 Pro Max 标准竖屏 CSS 视口 428×926；Pura X 展开阔屏按可用宽度自适应，480/528/540px 为检查参考，不将其作为已测设备值。手机显示缩放、浏览器工具栏和键盘会改变可视高度。
400px 起标题与账本、成对筛选字段并排；低于 400px 回退单列。480px 起筛选分类四列、编辑分类五列、分页信息与按钮并排。768px 起汇总四列；横屏弹层保留内部滚动，安全区覆盖刘海与手势条。
输入字号至少 16px，主要按钮和查询控件至少 48px，避免 iOS 自动输入放大；页面双指缩放按用户要求禁用，系统级辅助放大不由网页控制。账单金额独立列，付款与录入人放下一行。编辑旧账单不自动弹键盘。
弹层通过 VisualViewport 更新高度/顶部，头部与底部操作区固定，表单独立滚动；无该 API 时使用 dvh/vh 回退。关闭后恢复背景位置，不将固定屏高或机型 UA 写入布局逻辑。

四页信息主次：账本＝浅绿结余主区 + 暗红记账主按钮，模板/最近记录次之；统计＝大额支出 + 收入支出对比条，分类排名/付款分布次之；明细＝紧凑搜索与条件、匹配汇总、账单列表；我们＝成员头像与邀请主区，账号行与退出次之。各页面分别使用 home.css、reports.css、records.css、together.css，避免同一个卡片模板重复四次。

统计趋势：页首提供日/月/年分段按钮，触点至少 44px；日视图选择月份，月视图选择年份，年视图展示历年。首要图表使用 2px 暗红 SVG 折线、浅灰参考线、固定高度金额读数，无渐变填充；曲线按实际数据连线，不平滑篡改极值。坐标随可用宽度缩放，文字保持 CSS 字号，横轴最多 5 个标签；触摸点选、方向键和可展开数据表均可读取精确金额。图表内容切换 240ms 淡入，遵循减少动态效果；收支、分类、成员分析跟随同一统计范围。

抽屉组件分工：BottomDrawer 负责 Portal、从下向上展开/向下关闭、遮罩/Escape、焦点与滚动恢复；EntryDrawer 只负责金额/分类/付款人/日期/模板表单；EntryComposer 在共享布局挂载一次，全局新账单写入后刷新当前页面。保持打开高度，不自动唤起键盘；按钮使用颜色反馈，避免按下位移。

全局动效实现：ui/motion.css 统一 180ms 操作反馈/退出、240ms 内容淡入/展开、280ms 页面/抽屉进入。Presence 由 React 状态和 animationend 保留退出子树；Collapse 用 CSS Grid 0fr/1fr 展开，不测量高度或直接修改 style。所有隐藏/退出内容 inert，减少动态效果设置立即完成显隐。业务层禁止手工增删 DOM、写 innerHTML/classList/style；视口变化订阅后进入 React style，滚动锁通过 CSS :has 声明。焦点、键盘遮挡时的内部滚动、Portal 宿主与下载 ref.click 集中在浏览器适配组件。正式产品的筛选、分类、模板、统计数据表、邀请和反馈复用这些组件；docs/review 的原型是历史离线演示，不是正式应用运行时。

桌面入口：暗红满底、米白「余」字图标，主体位于遮罩安全区；「我们」页使用现有边框、间距与 Collapse 展开安装步骤，不自动弹窗。

API 密钥二级设置：简洁面包屑与标题，一体式米白主面板，PC 左生成/右管理、手机单列。24px 内边距、细线分区、暗红单一主操作；列表通过图标、名称、状态及紧凑时间排列，空状态居中；生成成功替换原表单，浅红秘密输入框支持手动复制。教程默认折叠，环境变量仅展开后显示。无额外业务逻辑或设备断点。

账单来源：人工及历史缺省来源不显示标签。仅 AI 在分类旁显示紧凑「AI」标签，10px/500 深紫 #6655a6 字、14px 行高、4px 圆角、1px 5px 内边距（总高 16px），120deg 浅蓝 #edf3ff → 浅紫 #f3edff 渐变，12% 紫色内描边；aria-label/title 保留「AI 记录」。详情同步规则，不为人工标签保留空行。

账单左滑删除：两端首页与明细的主行向左拖动，右侧露出 88px 暗红删除按钮；点击后进入既有原因确认，不通过滑动直接删除。纵向滚动保留，拖动后屏蔽补发点击，向右滑或轻点已展开主行收起；桌面支持鼠标拖动及左右方向键/Escape。零位移时删除层 hidden 完全隐藏，负位移才显示红底；展开及拖动中前景保留 5px 圆角，右侧增加墨灰轻投影和细边，红色操作层使用内阴影，表现前后层次；收起后前景阴影在 180ms 内消退；未完全展开时操作 inert，忙碌/只读不可展开，评论区保持独立。鼠标按下即由原元素捕获以保留普通点击，横拖后由容器接管；6px 开始跟手、移动 28px 松手吸附展开/收起，斜向起步等待方向明确。可拖动主行禁止选中文字和原生拖放，桌面显示 grab/grabbing 光标。回弹 180ms，遵循减少动态效果。

账单金额留白：首页与明细共用 EntryRow，仅在金额元素右侧增加 12px 外边距，使价格与右边缘拉开距离；卡片、左侧内容、评论及上下间距均沿用原有布局。
